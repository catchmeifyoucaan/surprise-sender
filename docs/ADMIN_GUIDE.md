# Admin Guide

This guide provides instructions for administering the Surprise Sender application.

## User Management

- **View Users**: To view a list of all users, click the "Users" button in the sidebar.
- **Edit Users**: To edit a user, click the "Edit" button next to the user in the user list.
- **Delete Users**: To delete a user, click the "Delete" button next to the user in the user list.

## System Settings

- **SMTP Configuration**: To configure the SMTP settings, click the "Settings" button in the sidebar and then click the "SMTP" tab.
- **AI Configuration**: To configure the AI settings, click the "Settings" button in the sidebar and then click the "AI" tab.
